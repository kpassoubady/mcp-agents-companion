# MCP with AI Agents - Course Companion

Student companion repository for the **MCP with AI Agents** course. Contains hands-on labs, working examples, and exercises for learning the Model Context Protocol and building agent-based systems.

## Tech Stack

- **Primary Language:** JavaScript (Node.js 22+)
- **Core Framework:** Model Context Protocol (MCP) SDK
- **Content Type:** Course labs and demonstrations

## Directory Structure

| Directory | Purpose |
|:---|:---|
| `day1/` | Day 1 labs and demos for MCP fundamentals |
| `llm-context/` | Stores context and reference materials for LLM agents |
